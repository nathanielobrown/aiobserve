Context bar color prototypes, round 2

Five palettes, every one dark base → medium past → bright added, every bar 3px. Thread bars (session, run, maxed run) are muted gray; a compaction's freed span stays green. The first tree is invented so the calls chain the way a real turn's do; the second is a real fixture. Each variant's tokens are one block in this file's <style> under /* ── N · name ── */ — edit the hex values there to tweak.
